| 聯絡 | <apceaftaiwan@gmail.com> |

**不收的作品**（辦法第四條）：單純研究報告、文獻整理、概念提案、沒有實作的簡報、只交 Prompt、只用現成 AI 工具產生文字或圖片，以及**說明不出 AI 怎麼整合在作品裡**的作品。

### 評分（至少 3 位評審，逐項評分後平均）

| 項目 | 權重 | 說明 |
| --- | --- | --- |
| 創新性 | 25% | 服務構想、產品功能與 AI 運用方式的創新程度 |
| 使用者需求與實用價值 | 25% | 是否解決明確問題、有使用情境與實際價值 |
| AI 整合程度 | 20% | AI 是不是作品的核心功能，而不是包裝；**移除 AI 後主要功能不受影響的，評審得降低這項分數** |
| 實作完整度與可行性 | 20% | 原型完成度、穩定性、流程合理、落地可行 |
| 展示與說明 | 10% | 文件、影片、操作展示與表達清晰度 |

## 4. 作品對照評分的自評（2026-10-14）

10/13 上線兩個執行時用到 AI 的功能（`docs/plans/ai-questions.md`、`docs/plans/learning-report.md`，都用真的 Muse 在正式站驗收過），原本「執行時沒有 AI 推論」的弱點已經改變。

| 項目 | 強項 | 仍要注意 |
| --- | --- | --- |
| 創新性 | **AI 學習閉環**：學習分析找出弱項指標 → 一鍵針對這些指標 AI 出題 → 老師審核發佈 → 孩子在 3D 島上作答 → 指標統計回到分析。AI 出題依 108 課綱指標、可跨科，程式驗算答案與注音用字；3D 島嶼與班級即時連線讓練習像遊戲 | 單看「LLM 出題」不新，要強調閉環、課綱對齊、程式把關與給七歲孩子的安全設計 |
| 需求與實用 | 孩子（還不太識字，靠 AI 語音）、老師（出題與看弱點費時）、家長（看不懂分數）三種使用者都有對應畫面；依 108 課綱與三家教材版本；免費、平板瀏覽器就能玩 | 沒有實際使用數據（要寫的話，從正式資料庫唯讀統計，要你同意） |
| AI 整合 | 執行時：老師 AI 出題、AI 學習分析（孩子、家長、老師三種角度）都由伺服器呼叫 Meta Muse，strict JSON Schema 結構化輸出，伺服器檢查後才給人看。內容管線：3,533 句 AI 合成語音、Whisper 聽寫抽查。開發：265 次提交中 262 次有 Claude 署名 | **孩子端有規則後備**（伺服器沒開 AI 時改用規則建議），評審可能據此說「移除 AI 仍可運作」。寫法：後備是給七歲孩子的安全設計；老師端「依課綱跨科出題」「全班與個別弱項的文字分析」「分析接出題的閉環」沒有 AI 就得老師手工做，這是 AI 不可替代的部分。不要隱藏後備 |
| 實作完整度 | 兩個網址已上線；約 1,300 個單元測試案例、58 支 e2e（約 150 個情境）、多裝置測試；真的 Muse 的正式站驗收腳本 | AI 出題一批 5 題要 24～66 秒，影片要快轉並說明 |
| 展示與說明 | 影片用錄影腳本產生（可重錄）、AI 配音；說明書附架構圖與畫面 | — |

## 6. 待你決定或執行

1. 以個人或團隊名義參加（信件主旨與說明書封面要寫）。
2. 執行 `seed-demo.mjs` 建示範帳號（會在正式資料庫新增一位老師、一個班級、6 個示範孩子與作答紀錄），密碼只寫在你自己的報名填寫文件。
3. 影片上傳到哪裡（YouTube 不公開或 Google 雲端硬碟）：Gmail 附件上限 25 MB，影片放連結比較穩。
4. 寄件時間：建議 **10/24 前**寄出，留一週處理退信或連結打不開的問題。
5. 要不要在 `src/content/sources.ts`（家長專區「資料來源」頁）補登 Meta Muse：目前只寫在隱私權政策，沒有列在資料來源清單。這是程式修改，另外處理。

## 7. 製作指令（PowerShell 7）

```powershell
npm run build                                                         # 前端建置（錄影用 vite preview 的產物）
# ① 錄影與截圖：本機班級伺服器＋真的 Muse（讀 .env 的 LLM_ 變數，不用假出題器）
npx playwright test --config scripts/award/playwright.award.config.ts 2>&1 | Tee-Object -FilePath logs\award-record.log
# ② AI 配音（Fish Audio，讀 .env 的 FISH_API_KEY；--check 另外用 Groq Whisper 聽寫比對每一句）
node --env-file-if-exists=.env scripts/award/narration.mjs --check 2>&1 | Tee-Object -FilePath logs\award-narration.log
# ③ 剪接（字幕、配音、配樂）→ award-out\知識島大冒險-展示影片.mp4
node --env-file-if-exists=.env scripts/award/edit.mjs 2>&1 | Tee-Object -FilePath logs\award-edit.log
# ②③ 凱文大叔版本 → award-out\知識島大冒險-展示影片-凱文大叔.mp4
node --env-file-if-exists=.env scripts/award/narration.mjs --voice kevin --takes 3 2>&1 | Tee-Object -FilePath logs\award-narration-kevin.log   # 每句 3 個版本；試聽頁 award-out\voice\takes-kevin.html，換版本寫 award-out\voice\picks-kevin.json
node --env-file-if-exists=.env scripts/award/edit.mjs --voice kevin 2>&1 | Tee-Object -FilePath logs\award-edit-kevin.log
# 凱文大叔各聲音模型 × 問題句子的寫法，試聽比較頁（挑聲音與讀音修正用）
node --env-file-if-exists=.env scripts/award/voice-compare.mjs 2>&1 | Tee-Object -FilePath logs\award-voice-compare.log
Start-Process award-out\voice-compare\index.html
# ④ 架構圖 PNG、說明書 PDF、報名填寫 Word、系統畫面 zip
node scripts/award/build-docs.mjs --author "<創作者或團隊名稱>"
# ⑤ 正式站的示範老師帳號（先不加 --apply 看要建什麼；加了才寫入正式資料庫，密碼只印一次）
node scripts/award/seed-demo.mjs --server https://learning-island.zeabur.app --email <你收得到信的 email>
```

輸出都在 `award-out\`（不進版控）。① 產生截圖，④ 要在 ① 之後跑；剪接（③）的字卡與架構圖畫面也用到 ① 的截圖與 ④ 的 PNG。只改旁白文字時重跑 ②③。

分鏡與旁白在 `scripts/award/storyboard.mjs`；示範班級的資料（6 個示範孩子、全班最弱「鐘面的時刻」）在 `scripts/award/demoData.mjs`，錄影與正式站示範帳號共用。AI 出的題目與分析每次錄都不一樣，內容印在 `logs\award-record.log`，寄出前看一次。
