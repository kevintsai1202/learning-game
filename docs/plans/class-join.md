# 掃 QR code 加入班級（家長帳號、不用密碼）

> 狀態：**實作完成（2026-10-05），待上線**，總分期的批次 1.5（`docs/plans/roadmap.md`），做完就上線；之後接教師指引與家長指引。
> 相關文件：`docs/plans/accounts.md`（家長帳號、雲端角色）、`docs/plans/islands.md`（I1 一直連線）。

## 1. 使用者的需求（2026-10-05）

原話：「需要讓雲端的角色可直接加入班級，目前不容易操作。幫我用簡單一點，例如掃描 qr code 後家長可登入並取得已存在的雲端帳號加入班級。班級不要輸入密碼，已經綁定給老師維護了」

確認問題的回答：

- **密碼**：用家長帳號加入不用密碼；孩子要在學校平板用「代碼＋暱稱」登入時，老師在管理頁幫他設密碼。
- **掃描之後可以**（四項都要）：選已經存在的雲端角色加入、把這台裝置上的角色存到雲端再加入、新建一個角色加入、加入後就在這台裝置玩。
- **原本孩子自己用「代碼＋暱稱＋密碼」加入**：保留。
- **順序**：現在做，排在 I2 之前。
- 補充（同一天）：完成後要有**教師指引與家長指引**，在畫面上引導操作（下一批，形式另外確認）。

## 2. 現況

- 家長名下的角色加入班級：要在選角畫面點「🏫 班級」→「第一次加入」，輸入 6 位數代碼、暱稱、自己設 4 位數密碼（`POST /api/join` 帶孩子權杖）。家長帳號頁的孩子清單沒有「加入班級」。
- 孩子密碼（`accounts.pin_hash`）在第 5 版起可以空，但加入班級時一定會設。班級登入（`POST /api/login`）沒有密碼的帳號一律登入失敗。
- I1 起家長名下的孩子在自己的島上一直連線；中樞記著上線時的班級，加入班級後要重新上線才會換成新的班級與朋友。

## 3. 做法

### 3.1 老師：班級的 QR code

- 老師班級頁多一塊「📱 讓家長掃描加入」：QR code、加入連結（可以複製）。連結是目前網頁的網址＋`?join=<班級代碼>`（老師用 GitHub Pages 或 Zeabur 開，連結就指向同一個網址）。
- 「允許新的孩子加入」關閉時，這一塊顯示提醒「現在不開放加入，家長掃了也加不進來」。
- QR code 在瀏覽器裡產生（`qrcode` 套件，MIT），只在老師班級頁載入（動態 import，不加大孩子的首頁）。
- 成員表：沒有密碼的孩子，「重設密碼」寫成「設定密碼」（`MemberSummary.hasPin`）。

### 3.2 家長：打開加入連結

- 打開 `?join=123456`：網址參數先拿掉（重新整理不會再處理一次），直接到帳號頁。
- 還沒登入：登入或註冊畫面上方提示「登入家長帳號，讓孩子加入班級」；註冊時預先勾「家長」。
- 登入後帳號頁最上面出現「加入班級」面板，顯示班級名稱（`GET /api/parent/classes/:code`）。帳號沒有家長身分時提示到「帳號設定」勾選家長。
- 選要加入的角色：
  - 家長名下的雲端角色：還沒加入班級的可以選；已經在這一班的顯示「已經在這一班」；在別班的顯示「在○○班（要先退出才能換班）」。
  - 這台裝置上還沒存到雲端的角色：「存到雲端並加入」。
  - 「新建角色」：取名字、選動物與顏色，建在家長帳號下並加入。
- 班上的暱稱：預設是角色的名字，可以改；和班上其他人重複時請家長換一個。
- 加入後：「在這台裝置玩」（拿這台裝置的權杖、選這個角色、進島）或「完成」。這台裝置上已經有這個角色時寫「開始玩」。
- 家長帳號頁的孩子清單：還沒加入班級的角色多一個「🏫 加入班級」，輸入班級代碼後走同一個面板（不用掃描也能加入）。

### 3.3 伺服器

- `GET /api/parent/classes/:code`（家長權杖）：`{ room: { code, name }, joinOpen }`；找不到回 404 `no_room`。
- `POST /api/parent/kids/:id/class`（家長權杖、自己名下的角色）：`{ code, nickname }` → 加入班級，**不設密碼**（`pin_hash` 留空），存檔裡的名字改成暱稱。檢查和現有的加入相同：已經在班級裡 409、找不到班級 404、不開放加入 403、暱稱格式 400、暱稱重複 409。回傳 `{ kid: KidSummary }`。
- 和「帶孩子權杖加入」（`POST /api/join`）共用同一段加入邏輯，只差有沒有密碼。
- 班級登入：還沒有密碼的帳號照樣回「代碼、暱稱或密碼不對」（`bad_login`），不另外說「沒有密碼」——不然知道班級代碼的人可以用來試出班上有哪些暱稱。改在班級登入畫面放一行提示「家長幫你加入的，要先請老師設定密碼」。
- 加入班級後通知即時中樞 `onClassChanged(帳號)`：那個帳號線上的連線收到 `content`（同步拿到班級）並以 4005 關閉；裝置看到 4005 馬上重連，用新的班級與朋友上線。兩種加入都通知。

## 4. 隱私權政策

- 第 2 節「孩子的班級」：密碼改成「4 位數密碼（有設定時才有，只存雜湊）」；寫明家長可以用家長帳號讓孩子加入班級。中英文一起改，更新日期。

## 5. 測試

- 伺服器：家長加入（成功、別人的角色 404、已經在班級 409、不開放 403、暱稱重複 409、沒有密碼）、查班級、班級登入沒有密碼回 `no_pin`、老師設定密碼後可以登入、加入後通知中樞；中樞的 4005 重新上線。
- 純函式：加入連結的網址參數（讀、拿掉、組連結）。
- e2e：老師頁看到 QR code 與連結；家長打開連結 → 登入 → 選雲端角色加入 → 在這台裝置玩 → 進到班級島；存到雲端並加入、新建角色加入；老師成員表「設定密碼」後可以用班級代碼登入。

## 6. 實作紀錄

### 2026-10-05 完成，待上線

- **伺服器**：`joinExisting`（`server/app.ts`）是兩種加入共用的一段：檢查班級、開放加入、暱稱，交易裡鎖住帳號再確認沒有班級，暱稱撞到唯一鍵時回 `nickname_taken`；`pin` 是 null 時不設密碼。加入後呼叫 `onProfileChanged` 與 `onClassChanged`。家長的兩個路由在 `server/parents.ts`。
- **即時連線**：`hub.reconnect(帳號)` 以 4005（`CLOSE_RECONNECT`）關閉；裝置看到 4005 不算斷線、不封鎖，同步一次後馬上重新上線，換成新的班級島與朋友。
- **畫面**：`src/ui/screens/JoinQr.tsx`（老師班級頁的 QR code，`qrcode` 套件動態載入，建置時分成獨立的檔案）、`src/ui/screens/JoinClassPanel.tsx`（家長的加入面板）、`src/online/joinLink.ts`（加入連結的網址參數）。正在加入的班級存在 `useAccount.joining`，也放在 sessionStorage：註冊途中重新整理還在，關掉分頁就沒了。
- **新建角色**：直接建在家長帳號下（`POST /api/parent/kids`），不放進家長這台裝置的存檔；要在這台裝置玩時才下載。
- **測試**：`tests/server/class-join.test.ts`、`tests/server/ws.test.ts`（在自己的島上連線中的孩子被家長加入班級後，重新上線就在班級島）、`tests/server/hub.test.ts`（reconnect）、`tests/online/joinLink.test.ts`、`e2e/class-join.spec.ts`。
- **元素 id**：QR code 區塊與加入面板都有 `data-testid`，之後的教師指引、家長指引用來定位。
