## 2. 前後關係

- **I1 是其他即時功能的地基**：I2、I3、I4、G2 都建在「島」的中樞上。G2 如果先做，熊熊老師進島要先照「班級房間」寫一次，I1 改中樞時再改一次。
- **I2 之後老師才能去孩子的島**（G2 的「去班上孩子的島」用 I2 的移動島嶼）。
- **G2 的集合**要孩子在哪座島都收得到，靠 I1 的一直連線。
- **I3 要等 I2**：跨班朋友主要是為了互訪，沒有 I2 加了也沒地方玩。
- **I4 要等 I2**：對戰的兩人要在同一座島。
- **G4～G6（題目內容）和即時連線無關**，放哪裡都可以，也可以穿插在其他期之間。

## 3. 建議的上線順序

| 批次 | 期 | 為什麼這樣排 |
| --- | --- | --- |
| 1 | I1 | 地基先做；做完「我的島顯示離線」就解決了 |
| 2 | I2 | 去朋友的島，孩子最有感的功能 |
| 3 | G2＋G3 | 老師進島、公告、集合、發獎勵；建在島的中樞上，老師可以去孩子的島（隱私權政策一起更新） |
| 4 | I3 | 跨班朋友（隱私權政策一起更新） |
| 5 | I4 | 和朋友對戰 |
| 6 | G4～G6 | 老師更新題目內容（不急的話放這裡；老師急著要的話可以提前到任何一批之後） |
| 之後 | 島嶼佈置 | |

隱私權政策在批次 1、3、4 各更新一次（政策不能比功能晚上線）。
