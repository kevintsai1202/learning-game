# 一個孩子加入多個班級（例如學校的班級＋安親班）

> 狀態：**規劃（2026-10-06）**，待使用者確認第 8 節。
> 相關文件：`docs/plans/accounts.md`（第 6 節「一次只在一個班級」，這次推翻）、`docs/plans/class-join.md`（掃 QR code 加入）、`docs/plans/islands.md`（班級島、好友）、`docs/plans/login-ux-review.md`（L2～L5）、`docs/plans/roadmap.md`。

## 1. 使用者的需求（2026-10-06）

原話：「孩子可以在多個班級(例如安親班), 在別班也要能加入新班級」

這推翻 A2 的決定「一次只在一個班級」（已經在別的班級時回 409 `already_in_class`，要先退出才能換班）。

## 2. 現況：「只有一個班級」寫在哪裡

| 地方 | 現在的做法 |
| --- | --- |
| 資料表 `accounts` | 一個帳號一個 `room_code`、一個 `nickname`（班上不能重複：`UNIQUE (room_code, nickname_key)`）、一個孩子密碼 `pin_hash`；限制「班級與家長至少一個」 |
| 權杖 | 孩子權杖的「目前班級」從 `accounts.room_code` 讀；`tokens.room_code` 只是保留寫入 |
| 加入班級 | 擋 `already_in_class`：帶孩子權杖加入、家長讓孩子加入兩個路由各擋一次，兩者共用的 `joinExisting` 鎖住帳號後再確認一次；加入時存檔裡的名字改成班上的暱稱 |
| 老師 | 成員表、成員數、班級登入、重設密碼都用 `accounts.room_code` 查 |
| 送禮 | 同學名單、收禮清單、收下都用「我的班級」；禮物記在 `gifts.room_code` |
| 好友（I1） | 同班＝`room_code` 相同 |
| 即時中樞 | 班級島 `class:<代碼>` 由帳號的班級決定；`hello` 只說要去「班級島」 |
| 前端存檔 | `CloudLink` 只有一組 `room`、`roomName`、`roomCurriculum`；`island: 'mine'` 表示在我的島 |
| 畫面 | 島上「去我的島／回班級島」只有兩座島；家長專區教材分頁、班級帳號分頁、選角卡片、加入面板都只顯示一個班級 |

規模：伺服器 7 個檔、前端 9 個檔，加上 e2e，和島嶼互訪 I1（中樞改成島）差不多大。

## 3. 做法（草案）

### 3.1 資料表（第 10 版）

- 新表 `class_members`：帳號、班級、這個班的暱稱（班上不能重複）、這個班的孩子密碼（可以空）、加入時間；主鍵（帳號、班級）。
- 升級時把現有的「帳號的班級、暱稱、密碼」搬進 `class_members`；`accounts.room_code`、`pin_hash` 之後不再使用（資料表只往後加版本）。
- 「班級與家長至少一個」改由程式保證：最後一個班級被移出、又沒有家長的角色，照現在的規則刪除。
- `tokens.room_code` 開始真正使用：記這張 `class` 權杖是從哪個班的班級登入拿到的，老師移出或重設密碼時只撤銷那個班發的權杖。

### 3.2 名字

- 每個班級各自有暱稱（預設是角色的名字，和班上的人重複時才要換）。角色自己的名字不再被暱稱蓋掉：我的島、家長頁顯示角色的名字，班級島上顯示這個班的暱稱。

### 3.3 島

- 每個班級一座班級島（和現在一樣是 `class:<代碼>`）。島上的切換改成選單：我的島、二年三班的班級島、安親班的班級島。教材版本照那一班老師的設定。
- L5 的「📍 所在地標籤」寫出是哪一班（「📍 班級島・安親班」），兩件事一起設計。
- 舊版網頁只說要去「班級島」：進最近去過（沒有的話最近加入）的班級島。

### 3.4 朋友、聊天、送禮

- 朋友＝所有班級的同學與老師＋兄弟姊妹（I1 的「同班」改成「有共同的班級」）。
- 聊天、送禮的開關照所在那一座班級島的老師設定。
- 送禮對象：和自己有共同班級、而且那一班開放送禮的同學；禮物記在那個共同的班級。I2 會改成「送給朋友」，到時再調整。
- 位置：朋友看到「在班級島」（不寫哪一班，和 I1 兄弟姊妹的規則一樣）；老師看到自己班的孩子「在別的班級島」，不寫班名。

### 3.5 加入、退出、移出、登入

- 加入：已經在這一班回 409 `already_member`；超過上限回 409 `too_many_classes`；在別班照常加入。
- 家長讓孩子退出：選要退出哪一班；只結清那一班的禮物、只撤銷那一班發的權杖。
- 老師移出：只移出自己的班；沒有家長、也沒有其他班級時才刪除角色。
- 班級登入（代碼＋暱稱＋密碼）找那一班的成員；密碼是每個班各自的（L3 之後學校平板改用教室密碼，孩子密碼只當備援）。

### 3.6 前端

- 存檔的雲端標記改成班級清單（代碼、名稱、班級教材）＋現在在哪座島；舊存檔的那一個班級搬進清單（純函式，有單元測試）。
- 家長頁的孩子清單列出所有班級；「退出班級」選哪一班；加入面板裡在別班的孩子照樣能選。
- 家長專區的教材分頁：顯示各班老師統一的版本與我的島自己的版本。

### 3.7 隱私權政策

- 寫明一個孩子可以加入多個班級；每一班的老師與同學只看得到這一班的暱稱；老師看得到的學習進度是孩子全部的進度（和現在一樣包含我的島上玩的）；朋友與老師看不到孩子在別班的班名。中英文一起改。

## 4. 和其他批次的關係

- **L2（家長掃碼直接進教室）**：「孩子已經在別班」不再是要停下來的情況。
- **L3（學校平板的教室密碼）**：平板上列出的是「這一班的成員」，正好建在 `class_members` 上。
- **L5（島嶼差異）**：所在地標籤與選島選單一起做。
- **I2（去朋友的島、送禮改成對朋友）**：建在這次「有共同班級」的朋友計算上。

建議順序：**多班級 M → L2 → L3 → L4 → L5**。L2 的加入面板與 L3 的成員名單都建在「班級成員」上，先做 L2 的話，加入面板之後要再改一次。

## 5. 分期

| 期 | 內容 |
| --- | --- |
| M1 伺服器 | `class_members` 與升級、加入／退出／移出／班級登入／重設密碼／權杖／送禮／好友／中樞改用班級成員；舊版網頁相容（只說「班級島」時進最近的） |
| M2 畫面 | 存檔格式與升級、選島選單、家長頁與家長專區、加入面板、老師成員表的位置文字；隱私權政策 |

兩期一起上線（伺服器與網頁同一天換新版）。

## 6. 測試

- 伺服器：升級（第 9→10 版搬資料）、加入第二個班、上限、同一班 409、兩班的暱稱各自檢查、退出其中一班（只結清那一班的禮物、只撤銷那一班的權杖）、老師移出只影響自己的班、沒有家長也沒有其他班時才刪除、班級登入用那一班的暱稱與密碼、好友是有共同班級的人、中樞選哪座班級島、舊版的「班級島」。收尾用 Docker 的 PostgreSQL 跑（鎖定順序）。
- 前端：存檔升級與選島（純函式）；e2e：一個孩子在學校班級與安親班，兩座班級島各自的同學與教材，兩位老師各自看得到。

## 7. 不做的

- 兩個已經存在的角色合併成一個（例如孩子在兩個班各有一個老師建的角色）：進度合併牽涉金幣、道具、紀錄，另外規劃。

## 8. 待使用者決定

1. **名字**：每個班級各自的暱稱（建議，預設是角色名字），還是所有班級共用一個名字？
2. **上限**：一個孩子最多幾個班級？建議 5 個。
3. **沒有家長帳號的孩子**：加入第二個班級要不要先有家長帳號？建議要：家長用家長帳號掃第二個班的 QR code 加入。沒有家長帳號時，第二個班的老師會另外建一個角色，兩邊進度分開。
4. **順序**：先做多班級再做 L2（建議），還是 L2 先做、多班級之後再改加入面板？
