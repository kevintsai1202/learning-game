# 一個孩子加入多個班級（例如學校的班級＋安親班）

> 狀態：**M1＋M2 2026-10-06 17:17 上線（和 L2 一起）**；使用者的決定見第 8 節，實作細節見第 9 節，實作紀錄見第 10 節。第 9 節第 6 點（被移出時家長裝置不再保持離線）使用者 2026-10-06 確認。和 L2 一起上線。
> 相關文件：`docs/plans/accounts.md`（第 6 節「一次只在一個班級」，這次推翻）、`docs/plans/class-join.md`（掃 QR code 加入）、`docs/plans/islands.md`（班級島、好友）、`docs/plans/login-ux-review.md`（L2～L5）、`docs/plans/roadmap.md`。

## 1. 使用者的需求（2026-10-06）

原話：「孩子可以在多個班級(例如安親班), 在別班也要能加入新班級」

這推翻 A2 的決定「一次只在一個班級」（已經在別的班級時回 409 `already_in_class`，要先退出才能換班）。

## 2. 現況：「只有一個班級」寫在哪裡

| 地方 | 現在的做法 |
| --- | --- |
| 資料表 `accounts` | 一個帳號一個 `room_code`、一個 `nickname`（班上不能重複：`UNIQUE (room_code, nickname_key)`）、一個孩子密碼 `pin_hash`；限制「班級與家長至少一個」 |
| 權杖 | 孩子權杖的「目前班級」從 `accounts.room_code` 讀；`tokens.room_code` 只是保留寫入 |
| 加入班級 | 擋 `already_in_class`：帶孩子權杖加入、家長讓孩子加入兩個路由各擋一次，兩者共用的 `joinExisting` 鎖住帳號後再確認一次；加入時存檔裡的名字改成班上的暱稱 |
| 老師 | 成員表、成員數、班級登入、重設密碼都用 `accounts.room_code` 查 |
| 送禮 | 同學名單、收禮清單、收下都用「我的班級」；禮物記在 `gifts.room_code` |
| 好友（I1） | 同班＝`room_code` 相同 |
| 即時中樞 | 班級島 `class:<代碼>` 由帳號的班級決定；`hello` 只說要去「班級島」 |
| 前端存檔 | `CloudLink` 只有一組 `room`、`roomName`、`roomCurriculum`；`island: 'mine'` 表示在我的島 |
| 畫面 | 島上「去我的島／回班級島」只有兩座島；家長專區教材分頁、班級帳號分頁、選角卡片、加入面板都只顯示一個班級 |

規模：伺服器 7 個檔、前端 9 個檔，加上 e2e，和島嶼互訪 I1（中樞改成島）差不多大。

## 3. 做法（草案）

### 3.1 資料表（第 10 版）

- 新表 `class_members`：帳號、班級、這個班的暱稱（班上不能重複）、這個班的孩子密碼（可以空）、加入時間；主鍵（帳號、班級）。
- 升級時把現有的「帳號的班級、暱稱、密碼」搬進 `class_members`；`accounts.room_code`、`pin_hash` 之後不再使用（資料表只往後加版本）。
- 「班級與家長至少一個」改由程式保證：最後一個班級被移出、又沒有家長的角色，照現在的規則刪除。
- `tokens.room_code` 開始真正使用：記這張 `class` 權杖是從哪個班的班級登入拿到的，老師移出或重設密碼時只撤銷那個班發的權杖。

### 3.2 名字

- 每個班級各自有暱稱（預設是角色的名字，和班上的人重複時才要換）。角色自己的名字不再被暱稱蓋掉：我的島、家長頁顯示角色的名字，班級島上顯示這個班的暱稱。

### 3.3 島

- 每個班級一座班級島（和現在一樣是 `class:<代碼>`）。島上的切換改成選單：我的島、二年三班的班級島、安親班的班級島。教材版本照那一班老師的設定。
- L5 的「📍 所在地標籤」寫出是哪一班（「📍 班級島・安親班」），兩件事一起設計。
- 舊版網頁只說要去「班級島」：進最近去過（沒有的話最近加入）的班級島。

### 3.4 朋友、聊天、送禮

- 朋友＝所有班級的同學與老師＋兄弟姊妹（I1 的「同班」改成「有共同的班級」）。
- 聊天、送禮的開關照所在那一座班級島的老師設定。
- 送禮對象：和自己有共同班級、而且那一班開放送禮的同學；禮物記在那個共同的班級。I2 會改成「送給朋友」，到時再調整。
- 位置：朋友看到「在班級島」（不寫哪一班，和 I1 兄弟姊妹的規則一樣）；老師看到自己班的孩子「在別的班級島」，不寫班名。

### 3.5 加入、退出、移出、登入

- 加入：已經在這一班回 409 `already_member`；超過上限回 409 `too_many_classes`；在別班照常加入。
- 家長讓孩子退出：選要退出哪一班；只結清那一班的禮物、只撤銷那一班發的權杖。
- 老師移出：只移出自己的班；沒有家長、也沒有其他班級時才刪除角色。
- 班級登入（代碼＋暱稱＋密碼）找那一班的成員；密碼是每個班各自的（L3 之後學校平板改用教室密碼，孩子密碼只當備援）。

### 3.6 前端

- 存檔的雲端標記改成班級清單（代碼、名稱、班級教材）＋現在在哪座島；舊存檔的那一個班級搬進清單（純函式，有單元測試）。
- 家長頁的孩子清單列出所有班級；「退出班級」選哪一班；加入面板裡在別班的孩子照樣能選。
- 家長專區的教材分頁：顯示各班老師統一的版本與我的島自己的版本。

### 3.7 隱私權政策

- 寫明一個孩子可以加入多個班級；每一班的老師與同學只看得到這一班的暱稱；老師看得到的學習進度是孩子全部的進度（和現在一樣包含我的島上玩的）；朋友與老師看不到孩子在別班的班名。中英文一起改。

## 4. 和其他批次的關係

- **L2（家長掃碼直接進教室）**：「孩子已經在別班」不再是要停下來的情況。
- **L3（學校平板的教室密碼）**：平板上列出的是「這一班的成員」，正好建在 `class_members` 上。
- **L5（島嶼差異）**：所在地標籤與選島選單一起做。
- **I2（去朋友的島、送禮改成對朋友）**：建在這次「有共同班級」的朋友計算上。

建議順序：**多班級 M → L2 → L3 → L4 → L5**。L2 的加入面板與 L3 的成員名單都建在「班級成員」上，先做 L2 的話，加入面板之後要再改一次。

## 6. 測試

- 伺服器：升級（第 9→10 版搬資料）、加入第二個班、上限、同一班 409、兩班的暱稱各自檢查、退出其中一班（只結清那一班的禮物、只撤銷那一班的權杖）、老師移出只影響自己的班、沒有家長也沒有其他班時才刪除、班級登入用那一班的暱稱與密碼、好友是有共同班級的人、中樞選哪座班級島、舊版的「班級島」。收尾用 Docker 的 PostgreSQL 跑（鎖定順序）。
- 前端：存檔升級與選島（純函式）；e2e：一個孩子在學校班級與安親班，兩座班級島各自的同學與教材，兩位老師各自看得到。

## 7. 不做的

- 兩個已經存在的角色合併成一個（例如孩子在兩個班各有一個老師建的角色）：進度合併牽涉金幣、道具、紀錄，另外規劃。

## 8. 使用者的決定（2026-10-06）

1. **名字**：每個班級各自有暱稱，預設用角色名字，只有和班上同學撞名時才要換。
2. **上限**：一個孩子最多 **5 個**班級。
3. **沒有家長帳號的孩子**：加入第二個班級要用家長帳號掃 QR code。沒有家長帳號時，第二個班的老師會另外建一個角色，兩邊進度分開，之後也不能合併。
4. **順序**：先做多班級（M），再做 L2。


## 9. 實作細節（動工前的判斷，2026-10-06）

使用者決定的四點以外，實作時要定的細節。以「規則單純、和現有行為一致」為原則：

1. **資料表第 10 版**：`class_members`（帳號、班級、暱稱、`nickname_key`、孩子密碼、加入時間；主鍵（帳號、班級），`UNIQUE (room_code, nickname_key)`）。升級時把 `accounts` 的班級、暱稱、密碼搬過去，拿掉 `accounts_class_or_parent` 限制；`accounts.room_code`、`pin_hash` **先不清空、之後不再讀也不再寫**（Zeabur 換版時舊的伺服器還會服務一兩分鐘，清空會讓它以為所有孩子都沒有班級）。新建的角色這兩欄是空的。舊欄位留著的代價：刪除班級時外鍵仍會連帶刪掉舊欄位指到那一班的角色，目前只有兩支部署腳本會刪班級（這次一起改寫）；上線穩定後再用下一版清掉。`accounts.nickname` 保留，只當角色的備用名字。
2. **名字**：加入班級不再把存檔的名字改成暱稱（已經改過的舊資料不動）。班級島上顯示那一班的暱稱，自己的島顯示角色的名字。好友名單上的名字：同學用「最早建立的共同班級」裡的暱稱（兩邊看到的是同一個班的暱稱），兄弟姊妹用角色名字。
3. **權杖**：`tokens.room_code` 記「用哪一班的代碼登入」（現有的權杖本來就有寫）。老師移出、重設密碼只撤銷那一班發的 class 權杖：條件一定是 `via = 'class' AND room_code = 那一班`（家長權杖的 `room_code` 是發權杖當時的班級，不能拿來判斷）。孩子權杖的身分改成「所有班級的清單」。
4. **加入**：已經是這一班的成員回 409 `already_member`；已經有 5 個班級回 409 `too_many_classes`（鎖住帳號後再數一次）。帶孩子權杖加入（班級畫面的「第一次加入」）：沒有家長帳號、已經有班級的角色回 409 `need_parent`，請家長用家長帳號掃 QR code（第 8 節第 3 點只限制沒有家長的孩子）；有家長帳號的角色照樣可以加入（L3 已拿掉班級畫面的「第一次加入」，帶權杖加入的 API 保留給舊版網頁與測試）。
5. **退出與移出**：家長退出要指定哪一班（舊版網頁沒給、而且只有一個班級時退出那一班）。老師移出只影響自己的班：結清這一班的禮物（有家長兩個方向都退、沒有家長只退別人送他的）、撤銷這一班的 class 權杖；沒有家長、也沒有其他班級時才刪除角色。
6. **即時連線**：`hello`、`go` 多一個 `room`（班級代碼），沒給時進最早加入的班級島（舊版網頁）；`welcome` 帶回是哪一班。退出或被移出其中一班時：用**那一班**代碼登入的連線照舊踢下線（權杖也撤銷）；家長裝置與其他班的連線不踢，以 4005 重新上線（拿新的班級與朋友），並送一則提示（熊熊老師的泡泡）。**這改變了 I1 使用者確認過的「被移出的孩子那次遊玩保持離線」**（`islands.md` 第 12 節），使用者 2026-10-06 確認可以。
7. **送禮**：同學名單與送禮可以帶 `room`（現在所在的班級島），只列、只送那一班的同學，禮物記在那一班；沒帶時（舊版網頁）列出所有班級的同學、記在最早建立的共同班級。收禮清單與收下涵蓋所有目前的班級。
8. **老師看得到的位置**：成員表的「在哪裡」多一種「在別的班級島」（不寫班名）。
9. **前端存檔**：`CloudLink` 改成班級清單（代碼、名稱、班級教材）＋現在在哪座島（`island` 是 `'mine'` 或班級代碼，沒有表示最早加入的班級）。舊存檔的 `room` 在載入時轉成清單（純函式），存檔版本不升（欄位可以省略）。
10. **選島**：只有一個班級時維持「去我的島／回班級島」一顆按鈕；兩個以上時按鈕寫「🏝️ 換島」，打開選單列出我的島與各班。所在地標籤與場景差異留給 L5。本機記住的島只要那一班還在清單裡就保留（原本是「同一個班級才保留」）。
11. **相容**：伺服器的回應同時帶 `rooms`（新）與 `room`（第一個班級），部署途中的舊版網頁照樣能用。「第一個班級」一律是最早加入的（`joined_at`，同時加入再比班級代碼）：回應裡的 `room`、沒說哪一班時進的班級島、前端沒選過時的班級島都用同一個定義。「共同班級」（好友名單的暱稱、舊版網頁送禮記在哪一班）則用最早建立的那一班（`rooms.created_at`，再比代碼），兩邊看到的一致。
12. **部署腳本**：`purge-test-rooms`、`delete-empty-rooms`、`inspect-prod-data` 改用 `class_members` 數成員、找測試資料；刪測試班級後，沒有家長也沒有其他班級的角色一起刪。


## 10. 實作紀錄

### M1＋M2（2026-10-06 17:17 和 L2 一起上線）

- **伺服器**：資料表第 10 版 `class_members`（搬既有資料、拿掉「班級與家長至少一個」限制；舊欄位不清空）。`server/classes.ts`：第一個班級的順序、離開某一班（`leaveClass`）、只撤銷那一班的 class 權杖（`revokeClassTokens`）、好友名單的名字（`sharedClassNames`，純函式）。權杖身分改成班級清單＋用哪一班登入（`tokens.ts`）。加入（上限 5、`already_member`、沒有家長的孩子加第二班 `need_parent`）、班級登入與密碼（每一班各自的）、老師成員表（這一班的暱稱、`hasPin`、在別的班級島）、老師移出與家長退出（只影響那一班）、送禮（`room` 參數、收禮跨班、退出只結清那一班）、`/api/me`／同步／登入回應帶 `rooms`（`room` 給舊版網頁）。即時中樞每一班一座班級島（`hello`／`go` 帶 `room`、`welcome` 帶 `classCode`、`notice` 訊息、`leftClass`），好友名單的名字照各自看到的。
- **前端**：存檔的雲端標記改成班級清單＋所在的島（載入時把舊格式轉過來，`upgradeCloud`）；`island.ts` 的 `currentClass`；同步用 `withRooms` 更新班級清單；即時連線帶班級代碼、比對伺服器回的班級、收到 `notice` 顯示熊熊老師的泡泡；島上有好幾個班級時「🏝️ 換島」選單；家長頁每一班一顆「退出」、在別班的孩子也能「加入班級」；加入面板（也在別班、已經有 5 個班級）與加入後直接進那一班的班級島；家長退出或加入後馬上同步這台裝置上的角色（`useCloud.syncKid`）；家長專區的教材說明與班級欄位列出每一班；老師成員表「在別的班級島」；送禮帶現在所在的班級。
- **部署腳本**：`purge-test-rooms`、`delete-empty-rooms`、`inspect-prod-data` 在第 10 版起看 `class_members`；刪班級前先清空指向那些班級的舊欄位，另外刪掉測試班級裡沒有家長、也沒有其他班級的純班級角色。
- **隱私權政策**：中英文第 2 節（一個孩子最多 5 個班級、每一班各自的暱稱與密碼）、第 5 節（同學只看到那一班的暱稱、老師看不到孩子還在哪些班、老師看到「別的班級島」）、刪除與移出（只離開那一班）。

和規劃不同、或規劃沒寫到的：
