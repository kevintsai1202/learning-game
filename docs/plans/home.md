# 自己的家（島嶼動森化）規劃

> 狀態：**規格確認（2026-10-11）**；**第一期（院子）2026-10-11 04:55 上線；改版（在島上直接佈置全島）10:07 上線**，實作紀錄見第 6 節。總分期見 `docs/plans/roadmap.md`（批次 5）；使用者的決定見第 2 節。
> 相關文件：`docs/plans/islands.md`（自己的島、朋友來玩）、`docs/plans/login-ux-review.md` 第 4.5 節與 `docs/decisions.md`（L5 的小屋）、`docs/plans/rewards.md`（百寶屋、商品目錄）。

## 1. 需求

- 使用者 2026-10-07：自己的島**長期朝《動物森友會》的方向**——自己的家、進屋、佈置。L5 已經在自己的島西南角放了孩子的小屋（門朝出生點、門前留空地），從這裡擴充。
- 金幣的主要用途是百寶屋的裝扮；佈置讓金幣多一個用途，鼓勵孩子繼續學習。

## 2. 使用者的決定（2026-10-11）

1. **先院子、再進屋，分兩期**；第一期（院子）做完就上線。
2. **擺放用格子點選**：進佈置模式，從家具包點一個，再點亮起來的格子放下。
3. **家具一個一個買**：擺一個就要有一個，同一種可以買很多個；小東西便宜、大東西貴。
4. **範圍是小屋周圍的院子**（約 50 格），不是整座島。

## 3. 第一期：院子

### 3.1 院子的格子

- 以小屋為中心，格子 1 公尺見方，取半徑 5.5 公尺內的格子，去掉：
  - 小屋本體（小屋半徑 2.1＋0.5）；
  - 小屋門口往出生點方向的走道（門口往前 3 格，寬 1 格）；
  - 建築、步道、廣場、出生點附近（沿用種樹的 `isFree`）；
  - 草地外緣（`WALK_RADIUS − 0.8` 以外）。
- 格子用相對小屋的整數座標 `(gx, gz)` 表示（以後院子形狀小改，舊的擺放大多還在原位）。院子的計算寫成純函式 `yardCells()`（`src/store/yard.ts`，伺服器共用），單元測試檢查格子數、不碰到小屋與建築、都在草地上。
- 院子裡原本的樹全部移開（`treesAway` 的半徑改成院子的半徑）。

### 3.2 家具（第一期 21 種）

全部原創，用程式畫的低多邊形模型（`src/world/Furniture.tsx`），一樣家具佔一格、可以轉四個方向。價格參考：答一回合約拿 10～16 枚金幣，帽子 20～150 枚。

| 類別 | 家具（價格） | 擋路 |
| --- | --- | --- |
| 花草 | 紅花圃（8）、黃花圃（8）、鬱金香（10）、草叢（5）、蘑菇（10）、石板路（5） | 不擋路 |
| 植物 | 小樹（20）、灌木（15） | 擋路 |
| 戶外家具 | 木柵欄（6）、長椅（40）、野餐桌（60）、遮陽傘（50）、路燈（45）、信箱（30）、稻草人（50）、木箱（20） | 擋路 |
| 遊樂 | 鞦韆（120）、溜滑梯（150）、沙坑（80）、風車（90）、小池塘（100） | 擋路（小池塘不擋路） |

- 每種家具最多擁有 20 個；院子最多擺 60 個（效能）。
- 價格與種類之後可以調整（只改目錄）。

### 3.3 百寶屋

- 新分頁「🏡 家具」：卡片顯示價格與「已有 n 個（擺了 m 個）」，按一次買一個。
- 沿用 `buy` 操作：家具（id 開頭 `decor.`）可以重複買，收藏裡同一個 id 出現幾次就是有幾個（不另外存數量）；超過 20 個不能再買。伺服器照同一份規則扣金幣。

### 3.4 佈置模式

- 在自己的島上（不是拜訪朋友時），島上 HUD 多「🏡 佈置」按鈕。進入時角色停下，鏡頭轉到院子上方俯視，地上出現格子。
- 下方「家具包」列出有的家具與還能擺幾個；點一個 → 可以擺的空格子亮起來 → 點格子放下（可以連續放）。
- 點已經擺好的家具：「🔄 轉方向」「↔️ 移動」（再點一個空格子）「📦 收起來」。
- 「✅ 完成」存檔、鏡頭回到角色；「✕ 取消」放棄這次的改動。
- 沒有家具時，家具包提示「到百寶屋買家具吧！」。
- 熊熊老師、拜訪中的朋友沒有這個按鈕。

### 3.5 存檔與操作

- `Profile.yard`（選填，舊存檔沒有就是空院子）：`{ id, gx, gz, rot }[]`。
- 新操作 `yard { items }`：整份取代。套用時拿掉不合法的項目（不是家具、格子不在院子裡、格子重複、超過擁有的數量、超過 60 個），其餘照存；伺服器用同一份規則（`src/online/ops.ts`）。
- 收藏的家具數量直接數收藏裡的 id；擺放不扣收藏（收起來就回到家具包）。

### 3.6 朋友看得到

- 進自己的島時，`welcome` 多 `yard`（島主的院子），來玩的朋友與熊熊老師都看得到；島主按「完成」後，伺服器送 `yard { items }` 給島上其他人。舊版網頁不認得，會忽略（看不到佈置，不會壞）。
- 單機與沒有雲端角色的孩子：存在裝置上，自己看得到。

### 3.7 碰撞

- 擋路的家具（半徑 0.45）加進碰撞；不擋路的花草、石板路、小池塘可以走過去。

### 3.8 隱私權政策

- 第 12 節「佈置自己的島與小屋」的院子部分搬進第 2 節（存檔多了院子的擺設）與第 5 節（來玩的朋友、熊熊老師看得到院子）；屋內等第二期再搬。

## 4. 第二期：進屋（概要，第一期上線後再細談）

## 7. 第一期改版：在島上直接佈置全島（2026-10-11，使用者試玩後）

使用者試玩後的回饋（2026-10-11）：「佈置後沒辦法顯示出來，只能透過佈置看到；我需要做成像動森這樣能直接佈置到島上」「只有這一小塊有點小，讓我能佈置全島」「（佈置的柵欄）會被其他建築物擋住，看能否走到建築物後就讓建築物隱形」；另外「柵」沒有注音、聽起來是二聲。

使用者的決定（2026-10-11）：

1. **家具放在角色面前（動森做法）**，在平常的畫面佈置，不切換鏡頭。
2. **拿掉從上面看的「🏡 佈置」模式**。
3. **全島最多 300 個、每種最多 50 個**。
4. **走到建築後面時，擋住角色的建築變成幾乎看不見**（隱形）。

設計：

- **範圍**：自己的島上所有空草地，格子 1 公尺見方（座標仍然以小屋為原點）。避開：建築本體與門口、通往建築的步道、中央廣場與噴水池、出生點與碼頭、小屋與門口走道、島門牌、島上原本的樹、草地外緣。舊的院子擺設照新規則清理（大部分留著）。
- **放法**：島上 HUD 的「🎒 家具」打開家具包 → 選一樣 → 角色面前那一格出現半透明的家具（能放是綠框，不能放是紅框；可以先按「🔄」轉方向）→ 按「⬇️ 放下」；家具包可以連續放。走到擺好的家具旁邊（1.5 公尺內、最靠近的那一個）出現「🔄 轉方向」「👜 收起來」；移動就是收起來、走到別處再放。
- **存檔**：每次放下、轉方向、收起來都改存檔（不用按完成）；雲端角色的待送佇列裡，新的 `yard` 操作取代還沒送出的上一筆 `yard`（整份取代，連放很多個只送最後一份；同步時待送的操作會重新套用在伺服器的存檔上，本機的擺設不會被蓋掉）。
- **建築隱形**：每一格畫面判斷哪些建築（含小屋、百寶屋等）擋在鏡頭和角色之間，擋住的那一棟整棟隱形（`visible = false`；建築的材質有共用快取，改不透明度會連別棟一起變淡），走出來就恢復；隱形的建築點了不會進去。全部的島都有（班級島、朋友的島也一樣）。
- **注音與讀音**：重產注音字型子集（「柵」等新字）；「木柵欄」照試聽結果修正讀音。
- 朋友看得到、伺服器、存檔格式（座標範圍放寬）、碰撞照第一期。

## 8. 第二期：進屋（2026-10-11 開工前）

使用者的決定（2026-10-11）：

1. **走進一間房（動森做法）**：走到小屋門口「進去嗎？」→ 換成一間房，角色在房裡走；用和島上一樣的家具包，放在角色面前；從門口走出去回到島上。
2. **房間固定大小，一開始就大一點：10×10 格**（一格 1 公尺）。
3. 第一版：**室內家具約 15 種**、**換壁紙與地板**、**島上的家具也能搬進屋**（和島上共用同一份數量）。牆上掛的東西不做。
