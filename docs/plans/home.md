# 自己的家（島嶼動森化）規劃

> 狀態：**規格確認（2026-10-11）**；**第一期（院子）2026-10-11 完成，待上線**，實作紀錄見第 6 節。總分期見 `docs/plans/roadmap.md`（批次 5）；使用者的決定見第 2 節。
> 相關文件：`docs/plans/islands.md`（自己的島、朋友來玩）、`docs/plans/login-ux-review.md` 第 4.5 節與 `docs/decisions.md`（L5 的小屋）、`docs/plans/rewards.md`（百寶屋、商品目錄）。

## 1. 需求

- 使用者 2026-10-07：自己的島**長期朝《動物森友會》的方向**——自己的家、進屋、佈置。L5 已經在自己的島西南角放了孩子的小屋（門朝出生點、門前留空地），從這裡擴充。
- 金幣的主要用途是百寶屋的裝扮；佈置讓金幣多一個用途，鼓勵孩子繼續學習。

## 2. 使用者的決定（2026-10-11）

1. **先院子、再進屋，分兩期**；第一期（院子）做完就上線。
2. **擺放用格子點選**：進佈置模式，從家具包點一個，再點亮起來的格子放下。
3. **家具一個一個買**：擺一個就要有一個，同一種可以買很多個；小東西便宜、大東西貴。
4. **範圍是小屋周圍的院子**（約 50 格），不是整座島。

## 3. 第一期：院子

### 3.1 院子的格子

- 以小屋為中心，格子 1 公尺見方，取半徑 5.5 公尺內的格子，去掉：
  - 小屋本體（小屋半徑 2.1＋0.5）；
  - 小屋門口往出生點方向的走道（門口往前 3 格，寬 1 格）；
  - 建築、步道、廣場、出生點附近（沿用種樹的 `isFree`）；
  - 草地外緣（`WALK_RADIUS − 0.8` 以外）。
- 格子用相對小屋的整數座標 `(gx, gz)` 表示（以後院子形狀小改，舊的擺放大多還在原位）。院子的計算寫成純函式 `yardCells()`（`src/store/yard.ts`，伺服器共用），單元測試檢查格子數、不碰到小屋與建築、都在草地上。
- 院子裡原本的樹全部移開（`treesAway` 的半徑改成院子的半徑）。

### 3.2 家具（第一期 21 種）

全部原創，用程式畫的低多邊形模型（`src/world/Furniture.tsx`），一樣家具佔一格、可以轉四個方向。價格參考：答一回合約拿 10～16 枚金幣，帽子 20～150 枚。

| 類別 | 家具（價格） | 擋路 |
| --- | --- | --- |
| 花草 | 紅花圃（8）、黃花圃（8）、鬱金香（10）、草叢（5）、蘑菇（10）、石板路（5） | 不擋路 |
| 植物 | 小樹（20）、灌木（15） | 擋路 |
| 戶外家具 | 木柵欄（6）、長椅（40）、野餐桌（60）、遮陽傘（50）、路燈（45）、信箱（30）、稻草人（50）、木箱（20） | 擋路 |
| 遊樂 | 鞦韆（120）、溜滑梯（150）、沙坑（80）、風車（90）、小池塘（100） | 擋路（小池塘不擋路） |

- 每種家具最多擁有 20 個；院子最多擺 60 個（效能）。
- 價格與種類之後可以調整（只改目錄）。

### 3.3 百寶屋

- 新分頁「🏡 家具」：卡片顯示價格與「已有 n 個（擺了 m 個）」，按一次買一個。
- 沿用 `buy` 操作：家具（id 開頭 `decor.`）可以重複買，收藏裡同一個 id 出現幾次就是有幾個（不另外存數量）；超過 20 個不能再買。伺服器照同一份規則扣金幣。

### 3.4 佈置模式

- 在自己的島上（不是拜訪朋友時），島上 HUD 多「🏡 佈置」按鈕。進入時角色停下，鏡頭轉到院子上方俯視，地上出現格子。
- 下方「家具包」列出有的家具與還能擺幾個；點一個 → 可以擺的空格子亮起來 → 點格子放下（可以連續放）。
- 點已經擺好的家具：「🔄 轉方向」「↔️ 移動」（再點一個空格子）「📦 收起來」。
- 「✅ 完成」存檔、鏡頭回到角色；「✕ 取消」放棄這次的改動。
- 沒有家具時，家具包提示「到百寶屋買家具吧！」。
- 熊熊老師、拜訪中的朋友沒有這個按鈕。

### 3.5 存檔與操作

- `Profile.yard`（選填，舊存檔沒有就是空院子）：`{ id, gx, gz, rot }[]`。
- 新操作 `yard { items }`：整份取代。套用時拿掉不合法的項目（不是家具、格子不在院子裡、格子重複、超過擁有的數量、超過 60 個），其餘照存；伺服器用同一份規則（`src/online/ops.ts`）。
- 收藏的家具數量直接數收藏裡的 id；擺放不扣收藏（收起來就回到家具包）。

### 3.6 朋友看得到

- 進自己的島時，`welcome` 多 `yard`（島主的院子），來玩的朋友與熊熊老師都看得到；島主按「完成」後，伺服器送 `yard { items }` 給島上其他人。舊版網頁不認得，會忽略（看不到佈置，不會壞）。
- 單機與沒有雲端角色的孩子：存在裝置上，自己看得到。

### 3.7 碰撞

- 擋路的家具（半徑 0.45）加進碰撞；不擋路的花草、石板路、小池塘可以走過去。

### 3.8 隱私權政策

- 第 12 節「佈置自己的島與小屋」的院子部分搬進第 2 節（存檔多了院子的擺設）與第 5 節（來玩的朋友、熊熊老師看得到院子）；屋內等第二期再搬。

## 4. 第二期：進屋（概要，第一期上線後再細談）

- 小屋門口「進去嗎？」→ 室內房間（沿用同一個 3D 畫布，換場景）；格子地板＋牆面，擺床、桌椅、地毯，換壁紙與地板；朋友來玩可以進屋看。
- 沿用第一期的家具包、格子點選、存檔與「朋友看得到」。

## 5. 第一期分段（每段先寫會失敗的測試）

1. 規則：院子格子 `yardCells`、家具目錄、擺放檢查、`yard` 操作、家具可以重複買（單元測試，前端與伺服器共用）。
2. 家具模型與院子的 3D：院子畫家具、移開院子裡的樹、碰撞。
3. 百寶屋「🏡 家具」分頁。
4. 佈置模式：鏡頭、格子、家具包、放下／轉方向／移動／收起來、完成與取消。
5. 伺服器：`welcome` 帶院子、島主更新時送給島上的人；朋友的畫面畫出島主的院子。
6. 隱私權政策、預錄語音（新的固定句子）、文件、相關的 e2e（新的 `e2e/home.spec.ts`、百寶屋、朋友來玩看得到院子），上線。

## 6. 第一期實作紀錄（2026-10-11 完成，待上線）

照第 3 節與分段實作（每段先寫會失敗的測試），和設計不同或補充的地方：

- **院子的格子**（`src/store/yard.ts`）：半徑改成 **6 公尺**、建築邊緣留 0.6 公尺、步道兩側 1 公尺，算出來 **52 格**（種樹用的建築緩衝 1.6 公尺會吃掉百寶屋那一側，只剩 31 格）。西邊被草地外緣切掉。院子裡的樹與小花都移開。
- **規則**（前端與伺服器共用）：`yardCells`、`cleanYard`（拿掉不合法的項目，其餘照存）、`editYard`（佈置模式的純函式狀態：選家具、點格子、轉方向、移動、收起來）、`visibleYard`（不認得的家具跳過、最多 60 個，不丟例外）、`yardObstacles`。家具在商品目錄（`FURNITURE`，`slot: 'decor'`、`walkable`），穿戴的格子另外叫 `AvatarSlot`。家具不能當禮物。
- **存檔與操作**：`Profile.yard`（存檔格式最多 60 個，整份上傳的路徑也擋得住）；`yard` 操作；`buy` 操作讓家具重複買（每種最多 20 個，滿了拒絕）。`useGame.saveYard`。
- **伺服器**（`server/hub.ts`）：成員記院子；自己的島的 `welcome` 帶島主的院子（班級島沒有這個欄位）；`profileChanged` 比對院子，變了才送 `yard` 給島上其他人（遊玩時間等其他操作不送）。孩子的連線與熊熊老師的連線都寫 `src/online/useHostYard.ts`；畫面的單一來源：自己的島讀本機存檔，別人的島讀伺服器給的（`shownYard`）。
- **畫面**：家具模型 `src/world/Furniture.tsx`（21 種，院子整個用 StaticMerge 合併、院子換了就重新合併；風車的扇葉會轉）；佈置模式 `src/store/useYardEdit.ts` 與 `src/ui/DecorPanel.tsx`；島上 HUD 的「🏡 佈置」（`canDecorate`：單機的島與班級角色的我的島，拜訪朋友時沒有）；俯視鏡頭在 `Player.tsx`（佈置時角色不走路、點地面與建築沒有作用）；格子 `YardGrid`（可以放的空格子黃色、選起來的橘色；草地是綠的，用綠色看不出來）；佈置時藏起「○○的家」牌子（離鏡頭近時會蓋住格子）。佈置中收到益智對戰邀請自動回「正在忙」。
- **百寶屋**：「🏡 家具」分頁，卡片寫「已有 n 個（擺了 m 個）」，滿 20 個寫「滿了」。
- **隱私權政策**：院子搬進第 2 節（學習進度多「院子的擺設」）與第 5 節（來玩的朋友與熊熊老師看得到）；第 12 節留下「佈置小屋裡面」；更新日期 2026-10-11。
- **預錄語音**：`DECOR_LINES` 3 句（「還沒有家具」那句拆成兩句）與 21 樣家具的「買到○○了！」，共 25 句。Whisper 聽寫：「木柵欄」寫成「穆扎蘭」（同音字，但「柵」要唸ㄓㄚˋ，**要人工試聽確認讀音**），其他是同音字或異體字（郁金香、哦、在）。
- **測試**：`tests/store/yard.test.ts`、`tests/online/ops.test.ts`（院子與重複購買）、`tests/store/gifts.test.ts`（家具不能送）、`tests/store/island.test.ts`（`canDecorate`）、`tests/server/hub.test.ts`（院子 4 條）、`tests/online/hostYard.test.ts`；e2e `e2e/home.spec.ts`（21 種家具畫出來、佈置模式含一次真的點 3D 格子、百寶屋買家具、兩台裝置朋友看得到院子與更新）。e2e 用 `window.__game.yard`（格子、世界座標、佈置模式的動作、別人的院子）與 `window.__game.scene.project`（3D 座標換成畫面座標）。
- **已知限制**：部署途中新網頁送的 `yard` 操作會被舊伺服器以格式不符拒絕，那幾分鐘的佈置下次同步會被伺服器的版本蓋掉（和益智遊戲館第一批的空窗期一樣）。小屋北邊的家具從平常的鏡頭看會被小屋擋住（佈置時從上面看得到）。
