# 道具與成就規劃（P1.5）

狀態：R1（獎章、稱號）、R2（外觀道具）、R3（寵物、走路特效）已完成（2026-10-03），定案內容見 `docs/decisions.md`。

## 1. 使用者確認的範圍（2026-10-02）

使用者補充「道具要更多樣化，讓學生多學習有成就感」，四個方向全部要做，順序是「P1 驗收後先做道具，再進 P2」：

| 項目 | 內容 |
| --- | --- |
| 成就獎章＋專屬獎勵 | 學習里程碑解鎖獎章；部分道具只能靠獎章拿到，不能用金幣買；有獎章簿 |
| 更多外觀道具（金幣） | 帽子之外加眼鏡、背後（書包、披風、翅膀）、手持道具、走路特效 |
| 小寵物 | 跟在角色旁邊走；用金幣或獎章換；多人上線時同學看得到 |
| 稱號 | 名牌旁顯示，由獎章解鎖；多人上線時同學看得到 |

**設計原則**：成就感來自「學會了」，不是「玩很久」。獎章條件綁在三星、錯題本清掉、連續學習、寫字、挑戰塔、技能精熟，不綁遊玩時間；金幣道具讓「多練習」有回報，獎章道具讓「學會」有別人買不到的東西。

## 2. 學習統計（存檔新增，前後端同一套規則）

大部分條件可以從現有存檔算出來，只有兩個要新增計數：

| 統計 | 來源 |
| --- | --- |
| 一次答對總題數 | 各技能 `skills[*].firstTry` 加總（現有） |
| 各科三星活動數 | `bestStars` 等於 3 的活動，依活動所屬科目分組（現有） |
| 挑戰塔三星 | `bestStars['tower.*']` 等於 3（現有） |
| 技能精熟數 | `skills[*].box` 等於 5 的技能數（現有） |
| 連續學習天數 | `history` 的日期（有完成回合的日子），從最近一天往回數（現有，最多 300 回合） |
| **錯題清掉幾題** | 新增 `stats.wrongCleared`：錯題連續答對兩次、移出錯題本時加一 |
| **寫完幾個字** | 新增 `stats.written`：描寫題（`type: 'write'`）完成時加一 |

- 新欄位都可省略（舊存檔補 0），不升級存檔版本，比照 `voiceClips` 與 `cloud` 的做法。
- **舊存檔的既有成就**：三星、技能精熟、答對題數、連續天數都是從現有存檔算的，舊存檔在下一回合結束時自動補發；但「錯題清掉幾題」「寫完幾個字」是這一版才開始計數，**以前清掉的錯題與寫過的字不補算**（存檔裡沒有紀錄）。
- 連續天數用日期字串換算成天數（`Date.UTC`，不受裝置時區影響）比較是否相連；日期字串本身是裝置本機時間（伺服器設 `TZ=Asia/Taipei`），兩邊一致。
- 在 `recordSession` 裡更新，所以本機與伺服器（`applyOp`）算出來一定相同；`tests/online/ops.test.ts` 的對照測試繼續守住這點。

## 3. 獎章（18 個）

得到後就永久保留（之後條件變少也不收回），記在存檔 `badges`（獎章 id → 得到的日期）。在 `recordSession` 的**最後一步**檢查（星數、錯題本、歷史都更新完之後），所以達成條件的那一回合當下就拿到；前後端同一份規則（`src/store/badges.ts`）。

- R1 只記獎章與稱號。**專屬道具在 R2／R3 才發**：由 `grantBadgeItems(profile)` 依已得到的獎章補進收藏（同樣在 `recordSession` 裡呼叫），避免 R1 的收藏裡出現還沒有 3D 模型的道具。
- 稱號存的是獎章 id；畫面讀取時再確認那個獎章確實得到了，沒有就當作沒有稱號。

- **獎章簿**：島上 HUD 多一個 🏅 按鈕，列出全部 18 個獎章，得到的彩色、沒得到的灰色並寫出條件（「再清掉 3 題錯題」這種距離目標的提示）。家長專區的學習報告也列出獎章。
- **稱號**：有稱號的獎章得到後，可以在獎章簿選一個顯示；顯示在島上名牌旁（之後多人上線時，頭上暱稱上方也會顯示）。

## 4. 外觀道具與寵物（金幣 18 項＋獎章專屬 8 項）

角色外觀（`AvatarConfig`）多幾個欄位，都可省略：`face`（眼鏡）、`back`（背後）、`hand`（手持）、`trail`（走路特效）、`pet`（寵物）。每一格同時只能戴一個。

| 類別 | 金幣購買 | 獎章專屬 |
| --- | --- | --- |
| 帽子（現有 8 頂之外） | 🦖 恐龍帽 80、🐰 兔耳髮箍 50、🏴‍☠️ 海盜帽 90 | 探險家帽、勇者頭盔、學士帽 |
| 眼鏡 | 👓 圓框眼鏡 30、🕶️ 墨鏡 60、💗 愛心眼鏡 80 | — |
| 背後 | 🎒 小書包 50、🦸 紅披風 90、🪽 天使翅膀 150 | 金色披風 |
| 手持 | 🎈 氣球 40、🚩 小旗子 30、🌻 向日葵 60 | 星星魔法棒、毛筆 |
| 走路特效 | ✨ 閃亮星星 120、🌸 小花腳印 80 | — |
| 寵物 | 🐥 小雞 60、🦋 蝴蝶 80、🐠 小魚缸 100、🦕 小恐龍 150 | 小龍、貓頭鷹 |

- 價格參考：一回合大約賺 10～16 枚金幣，便宜的（30～50）玩兩三回合就買得到，貴的（120～150）要練一陣子。
- **百寶屋改成分頁**：帽子／眼鏡／背後／手持／特效／寵物。獎章專屬的道具也列在裡面，鎖起來並寫「需要獎章：段考勇士」，孩子看得到目標。
- **寵物**：跟在角色後方、慢一點跟上、上下飄動；角色停下來時在旁邊轉圈。**走路特效**：走路時腳下冒出星星或小花，幾秒後淡出（只在走路時出現）。
- 都是用基本幾何體做的 3D 模型；多人上線時其他人的外觀、寵物、特效也一起顯示。
- 道具名稱、獎章名稱、得到獎章的話放進 `src/ui/lines.ts`，跑盤點與預錄語音（約 50 句）。

## 5. 同步規則（雲端角色）

- `buy`：查目錄價格；**獎章專屬道具不能買**（拒絕「這個要用獎章換」）。
- `avatar`：每一格戴的東西都要已擁有，而且類別相符（例如不能把寵物戴在眼鏡格）。
- 新操作 `title`：選擇顯示的稱號，必須已得到那個獎章。
- 統計、獎章、專屬道具都在 `recordSession` 裡更新，伺服器套用 `session` 操作時自然算出相同結果。

## 6. 分期

| 期 | 內容 | 驗收 |
| --- | --- | --- |
| R1 | 統計、18 個獎章、得到獎章的慶祝畫面、獎章簿、稱號（顯示在名牌旁） | 玩完回合得到「初次冒險」；錯題清掉、描寫完成的計數正確；換裝置登入獎章還在 |
| R2 | 眼鏡、背後、手持、新帽子（含獎章專屬）、百寶屋分頁 | 買、戴、換裝置還在；獎章專屬道具鎖住、得到獎章後解鎖 |
| R3 | 寵物、走路特效；多人模擬畫面也顯示 | 寵物跟著走、特效只在走路時出現；手機版面稽核 0 問題 |

每期：單元測試（統計、獎章條件、同步規則）→ e2e（截圖並親眼確認辨識度）→ 預錄語音 → commit。
